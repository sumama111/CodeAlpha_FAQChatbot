# CodeAlpha FAQ Chatbot

A simple FAQ chatbot built for the CodeAlpha AI Internship using HTML, CSS, and JavaScript.

## Features
- Answers FAQs about CodeAlpha internship
- Cosine similarity-based question matching
- Interactive chat UI with quick question buttons
- Real-time responses

## How to Run
Open `index.html` in any web browser.

## Technologies Used
- HTML
- CSS
- JavaScript
